# Darkville Hapsis

Releases of Darkville Hapsis, by Darkville Labs: the desktop app for Windows and the `hapsis` terminal edition for Windows, macOS and Linux. This repository holds releases only.

- **Download:** the [latest release](https://github.com/hzyrgj001/hapsis/releases/latest). `Hapsis-Setup-<version>-x64.exe` installs the desktop app; the archives and packages are the terminal edition.
- **Updates:** installed copies update themselves from here. Every update is signed by Darkville Labs and checked before it's installed.
- **For AI agents:** [AGENTS_GUIDE.md](AGENTS_GUIDE.md) explains how agents such as Codex, Claude Code and Cursor can work with Hapsis, and [llms.txt](llms.txt) is its short index.
